Factory Inventory Management System

A full-stack demo for tracking inventory, orders, demand forecasts, backlog and spending. A Vue 3 single-page app talks to a FastAPI service that serves in-memory data loaded from JSON files. There is no database.

Data flow

  1. User changes a filter
    The FilterBar updates shared singleton refs in useFilters: period, warehouse, category and status.
  2. View requests data
    The view calls getCurrentFilters() and passes the result to a method in api.js. Values of all are omitted from the query string.
  3. HTTP GET to FastAPI
    For example GET /api/orders?warehouse=…&status=…&month=Q2-2025.
  4. In-memory filtering
    apply_filters matches warehouse, category and status. filter_by_month matches months or quarters against order_date.
  5. Validation and response
    Results are validated against Pydantic models and returned as JSON.
  6. Render
    The view stores raw data in refs and derives metrics and chart series with computed properties, which re-render the UI.
